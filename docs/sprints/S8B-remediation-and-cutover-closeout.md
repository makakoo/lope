Commit `0cc251b` (`S8: install, docs, release binary cutover, benchmarks, and evidence`) landed S7 and S8 handlers and installed `/usr/local/bin/lope`, **but** left measurable parity defects, loosened parity checks, outdated `FR39` docs, unapplied host/cross-repo patches, and unexecuted `A17` / `M1–M8` acceptance checks. This sprint closes every gap rigorously before S8 is declared complete or S9 (`OQ-4`) is evaluated.

**Operating constraints:**
- Every Rust change is built via `./scripts/cargo` (respecting NFR11 Xcode 14.2 pin).
- Zero loosened parity rules: `tools/parity/golden_run.py` must run strict comparisons with zero `"ignore"` hacks before closeout.
- External repo patches (`~/.lope`, `makakoo-jungle`, `makakoo-os`, `/Users/sebastian/MAKAKOO`) stay strictly scoped to the `PL`, `PG`, `PM`, `PH` contracts in [Spec 04](../specs/04-interfaces-and-protocol.md#L155-L183) and are verified/committed separately in each repository.
