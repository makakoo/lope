## Verification method

- Direct inspection of source, `git diff`, live state files and command output on the dogfood Mac.
- Four delegated read-only audits (one per repo). Load-bearing findings were re-run by the lead: the uncommitted `supervisor.py` diff, manifest outcome counts, `~/.lope/state` absence, `review --consensus` / `negotiate --max-rounds` definitions, Glimmer argv at `council-runner.ts:79` and `plan-build.ts:135`, `memory.db` schema, config `version` gate, nesting guard, `lope version` output and timing, `gym_lope_gate` imports, `setup/lope.rs`, Herdr rule ids, Zig requirement, Glimmer doctor regex and shim writer, absence of peer-credential code in Herdr.
- Baseline captures in [`docs/reference/`](../reference/) were generated by command, not written by hand.
