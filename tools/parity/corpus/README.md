Golden-run corpora. Each case: `name`, `argv` (as sent to the Rust `lope`),
optional `python_argv` (canonical Python argv, for DEC-11 normalisation
cases), `stdin`, `env`, `files` (fixture files in the cwd), `validators`, and
`expect` (`exit`, `exit_not`, `stdout_contains`). Fixture config and mock
validators are generated by golden_run.py.
